# Matriz de prioridades

Ferramenta de uma página (`index.html`, sem build) para organizar a semana pela matriz de Eisenhower.

- **Colar tarefas**: uma por linha. O app separa em *fazer agora*, *agendar*, *delegar* e *cortar*.
  - `1h`, `30min`, `1h30`: duração
  - `hoje`, `amanhã`, `seg`…`dom`, `qua 19h`: dia e horário
  - `→ ana` ou `@ana`: delegar
  - `#agora #agendar #delegar #cortar`: força um quadrante
- **Arrastar** tarefas entre quadrantes (no celular: segure e arraste). Com o foco numa tarefa, as teclas `1`–`4` também movem.
- **Plano da semana**: distribui *agora* e *agendar* de seg a sex conforme a capacidade diária; arraste entre os dias para fixar.
- **Replanejar semana** redistribui o que não está fixado e sugere o que mover quando um dia estoura.
- Tudo fica salvo no navegador (localStorage).

Para usar, abra `index.html` no navegador.
